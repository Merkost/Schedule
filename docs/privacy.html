Политика конфиденциальности

Приложение «Schedule». Последнее обновление: 13 мая 2026 г.

Schedule — приложение для ведения расписания работы научного оборудования Дальневосточного Федерального Университета (ДВФУ). Настоящая политика описывает, какие данные приложение собирает, для чего, и кому они передаются.

1. Какие данные собираются

  • Учётные данные Google — имя, e-mail, ссылка на аватар, идентификатор учётной записи Google. Используются только при входе через «Sign in with Google».
  • Профиль пользователя — имя, e-mail, аватар, роль (гость / пользователь / администратор), статус анонимности. Хранятся в Cloud Firestore.
  • Содержимое бронирований — выбранный прибор, дата и время, комментарии пользователя и менеджера, статус бронирования.
  • FCM Push-токен — для отправки уведомлений о статусе бронирований. Хранится в профиле пользователя.
  • Диагностические данные — отчёты о сбоях (Firebase Crashlytics), метрики производительности (Firebase Performance), агрегированные события использования (Firebase Analytics). Эти данные обезличены.

2. Зачем эти данные нужны

  • Создание учётной записи и идентификация пользователя в системе университета.
  • Создание, отображение, изменение и отмена бронирований.
  • Отправка push-уведомлений о новых заявках, подтверждениях и изменениях статуса.
  • Диагностика ошибок и улучшение стабильности приложения.

3. Кому передаются данные

Приложение использует следующие сервисы Google / Firebase в качестве подпроцессоров:

  • Firebase Authentication, Cloud Firestore, Cloud Functions, Cloud Messaging, Crashlytics, Performance Monitoring, Analytics for Firebase (Google LLC).
  • Google Sign-In (Google LLC) — только при выборе входа через Google.

Данные не передаются рекламным сетям, брокерам данных и сторонним сервисам аналитики. Приложение не использует рекламные идентификаторы (IDFA / GAID) и не отслеживает пользователей между приложениями или веб-сайтами.

4. Хранение и удаление данных

Профиль и бронирования хранятся в Cloud Firestore (Google Cloud, регион europe-west). Диагностические данные хранятся в инфраструктуре Firebase согласно стандартным срокам Google. Для удаления учётной записи и связанных с ней бронирований напишите запрос на e-mail ниже — данные будут удалены в течение 7 рабочих дней.

5. Дети

Приложение не предназначено для детей младше 13 лет и не собирает осознанно данные у этой возрастной группы.

6. Изменения политики

При существенных изменениях политики мы обновим дату в начале документа. Использование приложения после обновления означает согласие с новой редакцией.

7. Контакты

Вопросы, запросы на удаление данных и иные обращения: konstantin.merenkov@kttipay.com.

Privacy Policy

Schedule app. Last updated: 13 May 2026.

Schedule is a booking app for scientific equipment at the Far Eastern Federal University (FEFU). This policy describes which data the app collects, why, and with whom it is shared.

1. Data we collect

  • Google account data — name, e-mail, avatar URL, Google account ID. Only when "Sign in with Google" is used.
  • User profile — name, e-mail, avatar, role (guest / user / admin), anonymity flag. Stored in Cloud Firestore.
  • Booking content — selected appliance, date / time, user and manager comments, booking status.
  • FCM push token — used to deliver booking notifications. Stored as part of the user profile document.
  • Diagnostic data — crash reports (Firebase Crashlytics), performance metrics (Firebase Performance) and aggregated usage events (Firebase Analytics). This data is not linked to user identity.

2. Why we collect it

  • Account creation and identification inside the university system.
  • Creating, viewing, modifying and cancelling bookings.
  • Push notifications for new requests, approvals and status changes.
  • Diagnostics and stability improvements.

3. Sharing

Data is processed by the following Google / Firebase sub-processors:

  • Firebase Authentication, Cloud Firestore, Cloud Functions, Cloud Messaging, Crashlytics, Performance Monitoring, Analytics for Firebase (Google LLC).
  • Google Sign-In (Google LLC) — only if the user chooses Google sign-in.

No data is shared with advertising networks, data brokers or third-party analytics providers. The app does not use advertising identifiers (IDFA / GAID) and does not track users across other apps or websites.

4. Retention and deletion

Profile and booking data is stored in Cloud Firestore (Google Cloud, europe-west region). Diagnostic data follows Google Firebase default retention. To request deletion of your account and associated data, contact us at the e-mail below — we will action the request within 7 business days.

5. Children

The app is not directed at children under 13 and does not knowingly collect data from this age group.

6. Changes to this policy

If we make material changes we will update the date at the top of this document. Continued use of the app after an update constitutes acceptance of the revised policy.

7. Contact

Questions, deletion requests and other enquiries: konstantin.merenkov@kttipay.com.
